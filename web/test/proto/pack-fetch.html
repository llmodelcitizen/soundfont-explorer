M0b-6 SFPK pack fetch

Fetches an SFPK v1 pack whole and as header + single member via HTTP Range, parses it, decodes one member and schedules it; then measures keydown → source.start() latency, warm (buffer already decoded) vs cold (Range fetch + decode), 30 trials each, p50/p95. Params: ?pack=/work/proto/packs/0003.pk ?trials=30 ?autostart=1. After the automatic trials, every real ArrowDown/ArrowUp keypress runs one more trial (alternating warm/cold) so the owner can measure real input latency on a device.
